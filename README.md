# LinkUp — локальный мессенджер для команд и компаний

**LinkUp** — это легковесный, стильный и функциональный мессенджер, созданный для быстрого общения внутри локальной сети. Он идеально подходит для небольших компаний, офисов или учебных заведений, где не хочется зависеть от внешних серверов и публичных мессенджеров.

Всё, что нужно — запустить сервер в вашей сети, и пользователи смогут обмениваться сообщениями, файлами и настраивать интерфейс под себя.

---

## ✨ Возможности

- 🔐 **Регистрация и авторизация** — безопасный вход по логину и паролю.
- 💬 **Личные чаты** — общение один на один с любым пользователем.
- 📎 **Обмен файлами** — отправка изображений, документов, архивов и других файлов.
- 🎨 **Настраиваемый интерфейс**:
    - Светлая / тёмная тема.
    - 9 акцентных цветов (красный, оранжевый, жёлтый, зелёный, бирюзовый, голубой, синий, фиолетовый, розовый).
- 🗑️ **Управление сообщениями** — возможность удалять отправленные сообщения.
- 🔍 **Поиск пользователей** — находите коллег по имени и начинайте диалог.
- 📱 **Адаптивный дизайн** — удобно работать как с компьютера, так и с мобильного устройства.
- ⚡ **Автообновление чатов** — новые сообщения приходят без необходимости перезагружать страницу.

---

## 🖼️ Интерфейс

Интерфейс вдохновлён современными мессенджерами (Telegram-подобный стиль):  
- Плавные анимации сообщений.  
- Интуитивно понятная навигация.  
- Эффект ripple при нажатии на кнопки.  
- Кастомный скроллбар.

---

## 🛠️ Технологии

- **Frontend**: HTML5, CSS3 (CSS-переменные, Flexbox), JavaScript (ES6+).
- **Backend** (требуется отдельно): Node.js + Express + SQLite (или любой другой REST API, совместимый с форматом запросов, указанным в коде).
- **Хранение данных**: На сервере (пользователи, сообщения, файлы).
- **Стилизация**: Полностью адаптивная, с поддержкой динамической смены темы и акцентов.
